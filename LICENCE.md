## 🧩 About

**Unturned Map Overlay** is a comprehensive map companion for Unturned featuring a real-time minimap, loot tracker, vehicle spawn markers, waypoint navigation, and player position display.

Based on popular tools like **Unturned Map Tools**, **MapOverlay**, and community navigation mods.

---

## ✨ Features

### 🗺️ Core Map Tools
- Real-time minimap — see your position on the current map
- Loot tracker — mark and log nearby item spawns
- Vehicle spawn markers — highlight known vehicle locations
- Waypoint navigation — set and follow custom waypoints
- Player position display — coordinates and heading readout

### 🎨 Interface & Display
- Custom map skins — switch between overlay themes
- Zoom and pan controls — adjust the map view on the fly
- Marker icons — differentiate loot, vehicles, and waypoints
- Compass overlay — quick heading reference while moving

### 🏋️ Navigation & Training
- Route planner — plot multi-point travel paths
- Distance readout — measure distance to objectives
- Session tracker — record explored areas per session
- Map presets — save and load overlay layouts
